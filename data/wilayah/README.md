# Kode wilayah

Indonesia's regencies, districts and villages with their Kemendagri codes, which BMKG's forecast (api.bmkg.go.id) is asked by. Cosmo reads `index.json` to find a regency, then that regency's file (`35.24.json`) for its villages.

From [kodewilayah/permendagri-72-2019](https://github.com/kodewilayah/permendagri-72-2019) (CC0).
